# 93. 구현 검증 대기 — 실제 데이터로 확인해야 할 것

> **이 문서의 성격**: 2026-08-10 사용자 지시로 신설. 기업 답과 무관하게 **우리가 임의로 결정했고, 실제 사용·실제 데이터가 쌓여야 맞는지 확인할 수 있는 항목**을 모은다. `docs/92_기업답변_대기_임의값.md`와의 차이 — 92는 기업이 답하면 그 값으로 **교체**되는 것이고, 여기는 기업 답과 무관하게 **실측으로 검증**해야 하는 것이다.
> **지금은 구현을 막지 않는다.** 아래 값들은 이미 각 산출물에 구체값으로 채워져 있다 — 이 문서는 "나중에 검증할 것"의 색인이지, 지금 실행을 막는 게이트가 아니다.
> **`docs/40_검증계획.md`와의 관계**: `40`은 "지금 실행할 검증"만 둔다는 원칙이 있다(대기 항목은 `90`에 등록). 이 문서는 그 원칙과 부딪히지 않는다 — **아직 실행할 수 없는(데이터가 없는) 검증 대기 항목의 색인**이며, 실행 가능해지면 `40`이 V 번호를 받아 간다. `docs/90_미결정과_리스크.md`의 리스크 중 "실물 검증 안 됨" 계열도 같은 성격이라 여기서 인덱스만 링크한다(내용을 복제하지 않는다).
> **사용 시점**: 구현하다가 "이 값이 맞는지는 나중에 봐야 한다"는 생각이 들면 여기 추가한다. 실사용 데이터가 쌓이면 이 문서를 훑어 검증 가능해진 항목을 `40`으로 승격한다.
