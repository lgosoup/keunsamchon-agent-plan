# workflow.md — 실행 순서 개요

상세 정의(업로드용 원본)는 `package/automation/AGENT.md`. 여기는 한눈에 보는 요약이다.

```
회신 1통 입력
  → g7-interpret (컨텍스트 1): 원문층·해석층·판단층 생성
      → 수신거부="거부"/"의심" 즉시 발송금지.md 기록 (검증을 기다리지 않음)
  → g7-verify (컨텍스트 2, 판단층은 못 봄): 번역 검증 3층 + 원문 재스캔 수신거부 독립 확인
  → 오케스트레이터: T·V의 수신거부 판정 교차확인 (불일치 시 즉시 기록 + 사람에게 표시)
  → 실패 분기:
       판독 불가 → C8 확정, 검증 생략
       검증 불일치 1회차 → 재번역 1회 → 재검증 → 그래도 불일치면 C8
       검증층 비어있음 → 사용자에게 보내지 않음("검증 대기")
  → 최종화: replies/{수신일시}-{식별자}.md 저장 (무관용 3종 확인 후)
```

**확인 필요**: 조건부 재시도(재번역 1회)를 TimelyAI 자동화가 실제로 지원하는지 — `00_TimelyAI_매핑설계.md` 5절 참조.
