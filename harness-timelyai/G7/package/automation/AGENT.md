> 정본(이 harness 폴더 안): `../../spec.md`. 이 파일은 그 Spec의 「실행 형태 — Workflow다」절을 TimelyAI 자동화 단계로 옮긴 것이다.

## 입력

회신 원문(일본어, 그대로) + 헤더(발신 주소/수신일시/제목/스레드) + 첨부 파일명 목록 + 참조 발신 정보(있으면).

## 단계

**1단계 — `g7-interpret` 호출 (독립 컨텍스트 1)**
입력을 그대로 넘긴다. 출력: 원문층 + 해석층 + 판단층.

**1.5단계 — 수신거부 즉시 기록 (2단계를 기다리지 않는다)**
1단계 출력의 수신거부 값이 "거부" 또는 "의심→거부 처리"면, **2단계 호출 전에 먼저** 워크스페이스 파일 `발송금지.md`에 한 줄 append한다 (메일주소 / 근거 원문 인용 / 수신일시 / 출처파일명). 검증 결과를 기다리지 않는 이유: 법 요건(수신거부 처리)이 번역 정확도 검증보다 우선이다.

**2단계 — `g7-verify` 호출 (독립 컨텍스트 2, 1단계와 다른 호출)**
1단계 출력에서 **원문(일본어)과 한국어 해석 두 필드만** 추려서 넘긴다. 분류·판단층·참조 정보는 넘기지 않는다.

**3단계 — 실패 분기**

| 2단계 결과 | 처리 |
|---|---|
| 검증 3층 전체 일치 | 4단계(최종화)로 |
| 1단계에서 이미 C8(판독 불가) | 2단계를 생략하고 바로 4단계로 — 원문 그대로 사용자에게 |
| 검증 불일치 (1회차) | `g7-interpret`를 **재번역 지침**으로 1회만 다시 호출 → `g7-verify`를 다시 호출. 두 번째도 불일치면 **C8로 내리고** 원문 + 두 번역본 + 불일치 지점을 함께 4단계로 넘긴다 |
| 검증층이 비어 있음(V 호출 실패 등) | 4단계로 보내지 않는다 — "검증 대기"로만 남기고 사용자에게 올리지 않는다 |

**3.5단계 — 수신거부 교차 확인 (무관용, 4단계보다 먼저 확인)**
2단계(`g7-verify`) 출력의 "원문에서 발견한 수신거부성 표현" 항목과, 1단계(`g7-interpret`)의 수신거부 판정을 오케스트레이터가 대조한다.
- **둘 다 "있음/거부"로 일치** → 이미 1.5단계에서 기록됨. 추가 조치 없음.
- **V는 "있음"인데 T는 "거부 아님"으로 판정** (T가 놓친 경우) → **즉시 `발송금지.md`에 추가**하고, 최종 레코드의 사용자 조치 요청 칸에 "T·V 판정 불일치 — 수신거부 여부를 사람이 재확인할 것"을 반드시 적는다. 무관용 성공 기준(수신거부 누락 금지)이 여기서 걸리는 경우다.
- **T는 "거부"인데 V는 원문에서 못 찾음** → T의 판단 근거 인용이 있으므로 그대로 유지한다(V는 참고용 2차 확인이지 상위 판정자가 아니다). 다만 이 불일치도 사용자 조치 요청에 짧게 남긴다.

**4단계 — 최종화 (오케스트레이터가 직접 수행, 별도 스킬 호출 아님)**
1단계 출력(원문층·해석층·판단층) + 2단계 출력(검증층) + 3.5단계 교차확인 결과를 합쳐 `replies/{수신일시}-{식별자}.md` 파일 1개로 저장한다.
- 식별자: 참조 발신 정보에서 특정된 발송 건의 G1 식별자. 특정 불가면 발신 메일 주소 도메인을 임시 식별자로 쓰고 파일명에 `-미확정`을 붙인다.
- 저장 전 무관용 3종을 확인한다 — 하나라도 어기면 그 건을 사용자에게 보내지 않는다: (1) 일본어 원문이 그대로 있는가 (2) 부정·조건·가능/불가능 방향이 안 뒤집혔는가 (3) 수신거부·의심 건(3.5단계 교차확인 포함)이 `발송금지.md`에 빠짐없이 들어갔는가.

## 도구 권한 (자동화 전체)

회신 텍스트 읽기 + 결과 파일(`replies/*.md`, `발송금지.md`) 쓰기까지만. **어떤 단계에도 커넥터(resend 등 발신 도구)를 연결하지 않는 것이 원칙**이다 — "답장을 보내지 않는다"를 사후 점검이 아니라 권한 자체로 막으려는 것.

**확인됨(2026-08-05): `resend`는 워크스페이스 전체에 공용으로 연결되고 스킬/자동화 단위 개별 차단이 안 된다.** 그래서 이 자동화는 **resend가 아예 없는 G7 전용 새 워크스페이스**에 올리는 것을 전제로 한다 — 이게 1차 방어(권한 차단). `g7-interpret`·`g7-verify` 두 스킬 본문의 "resend·발신 도구를 절대 호출하지 않는다" 지침은 2차 방어로 남겨 둔다. **다른 워크스페이스(resend가 연결된 곳)에 이 자동화를 올리면 안 된다.**

## 확인 필요 (2026-08-05 기준 미확인)

TimelyAI 자동화가 **3단계의 "재번역 1회 재호출" 같은 조건부 분기/루프**를 실제로 지원하는지 확인되지 않았다. 지원되면 위 표 그대로 자동 실행한다. 지원되지 않으면: 2단계가 "불일치"를 출력한 시점에서 자동화를 멈추고, 사용자가 `g7-interpret`를 재번역 지침으로 수동 1회 재실행한 뒤 `g7-verify`를 다시 돌린다 — 그래도 불일치면 C8로 마감한다. 실제 TimelyAI 자동화 편집창에서 만들어 보며 확정한다.
