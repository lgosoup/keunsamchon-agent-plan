|---|---|---|---|---|---|
| `g7-interpret` (스킬) | 회신 원문 해석 + 8분류·수신거부·자동응답 1차 판정 | 회신 원문(일본어)·헤더·첨부명·참조 발신 정보 | 원문층·해석층·판단층 | 회신 텍스트 읽기 + `발송금지.md` append + 초안 파일 쓰기. **커넥터 없음** | 회신 1통 = 자동화 1회 실행 |
| `g7-verify` (스킬) | 번역 정확도 3층 검증 + 원문 재스캔한 수신거부 독립 확인 | **T 출력 중 원문·해석 두 필드만** (판단층 제외) | 검증층 + 독립 수신거부 스캔 결과 | 초안의 원문·해석 필드 읽기 + 검증층 쓰기. **커넥터 없음** | T와 별도 호출 — TimelyAI가 자동 분리 |
