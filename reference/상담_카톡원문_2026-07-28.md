# 실무자 상담 카톡 원문 (2026-07-28) — 수정 금지

## 이 자료의 지위 — 읽는 사람이 반드시 알아야 할 것

- **무엇인가**: 기업과제를 어떻게 해결할지·아이디어·검토 방향에 대해 **실무자(문성호, 컴공)에게 받은 상담** 내용 중 기억에 남은 것을 카카오톡에 메모장처럼 적어둔 기록이다. 강현규 본인의 정리·판단도 섞여 있다.
- **해당 기업(큰삼촌컴퍼니) 관계자가 아니다.** 기업의 요구사항이나 내부 사정을 말해주는 자료가 아니다.
- **절대적 진리도, 평가 기준도 아니다.** 이 문서의 문장을 근거로 "이렇게 해야 한다"고 단정할 수 없다.
- **동시에 신뢰할 만한 정보다.** 실무 경험이 있는 사람이 제시한 아이디어와 접근 방법이므로, 우리가 검토·채택할 후보로서의 가치는 높다.
- **따라서 취급 방식**: 여기서 나온 항목은 **우리가 채택한 작업 원칙의 출처**로 다루되(`docs/02_작업원칙.md`), 각 항목이 참인지는 별도로 검증한다. 심사·기업 미팅에서 "실무자가 그렇게 말했다"는 근거로 쓰지 않는다.
- 이 기록에 **없는 것**: 국가 선정 3축의 "K문화 수용성 / 현지화 가능성 / 확장 가능성", 메일 방식 3안, 커뮤니케이션 방식 2축. 이들은 별도 자료(본인 뼈대)에서 온 것이며 원문은 아직 확보되지 않았다 (`docs/99_기초아이디어_원안.md` 3절 참고).
