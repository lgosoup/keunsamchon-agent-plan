## 02_구에이전트 — 더 이상 쓰지 않는 서브에이전트 정의

- `be-agent` / `fe-agent` / `pd-agent` / `qa-agent` — 과거 "PDF 요약 웹앱" 개발용이라 이 프로젝트와 무관했고, 2026-07-29 삭제했다.
- 나머지 7종(`clarity` / `consistency` / `differentiation` / `feasibility` / `fit` / `specificity` / `demo-simulation`) — 지원서를 6개 기준(현실성·구체성·차별성·정합성·기업니즈부합도·표현력)으로 검토했던 에이전트 6종 + 데모 시뮬레이션 에이전트 1종.
  지원서 심사용으로 쓰였고 역할이 끝났다. 다만 **구현 산출물을 같은 기준으로 재검토하고 싶으면 프롬프트를 손봐 되살릴 여지는 있다** — 그 경우 `.claude/agents/`로 옮기고 대상 문서를 PDF에서 `docs/`로 바꿔야 한다.
  *(2026-07-30 디렉터리 정리: 위 4종이 삭제되고 남은 것이 이 7종뿐이라 `계획서검토/` 하위 폴더를 없애고 한 계층 올렸다.)*
