# 설계 검증 — 합성 테스트 케이스

> **테스트용 합성 데이터다 — 실제 기업과 주고받은 것이 아니다.** 아래 회신·발송 기록은 G7의 8분류와 G11의 집계·조정 제안 구조가 실제로 도는지 검증하기 위해 만든 가상의 예시다. `data/`에 쓰지 않는다 — 이 문서 안에서만 존재하는 설계 검증 자료다. 실제 회신·발송 데이터가 쌓이면 이 검증은 그 데이터로 다시 한다.

## G7 — 8분류 커버리지 검증

8개 분류 각각에 대해 합성 회신 예시를 하나씩 만들어, `criteria/g7-reply-processing.md` 1절의 판정 문장으로 실제로 갈리는지 확인한다.

| 분류 | 합성 회신(일본어, 요지) | 판정 근거 |
|---|---|---|
| **C1** 관심·진행 의향 | "ご提案いただきありがとうございます。詳細について一度オンラインでお打ち合わせできればと思います。来週水曜日はいかがでしょうか。" | 구체적 일정 언급("来週水曜日") — 표 1행에 정확히 걸림 |
| **C2** 조건부 관심 | "ご連絡ありがとうございます。興味はございますが、現在他の施策を優先しており、来期以降に改めて検討させていただければと存じます。" | "来期以降"으로 시기 유보 — 표 2행 |
| **C3** 거절 — 이유 있음 | "誠に恐縮ですが、現在は既存の制作会社と契約しておりますため、今回は見送らせていただきます。" | 거절 + 이유(기존 거래처) — 표 3행, 이유는 문안 개선 재료로 축적 |
| **C4** 거절 — 이유 없음 | "ご提案の件、今回は見送らせていただきます。ご了承ください。" | 거절만, 이유 없음 — 표 4행 |
| **C5** 담당자 아님 · 이관 | "恐れ入りますが担当部署が異なりますため、マーケティング部(marketing@example.co.jp)へ直接ご連絡いただけますでしょうか。" | 다른 창구 안내 — 표 5행, 새 주소는 연락처 갱신 정보원으로 G4에 전달 |
| **C6** 자동응답 | "このメールは送信専用アドレスです。本メールへのご返信には対応しておりません。" | 정형 자동회신 문구 — 표 6행, G6의 [회신]을 [무응답]으로 정정 |
| **C7** 무관·스팸 | "弊社の新商品キャンペーンのお知らせです。今すぐチェック！特別割引実施中。" | 제안과 무관한 광고성 내용 — 표 7행 |
| **C8** 판정 불가 | (첨부파일만 있고 본문 텍스트가 없음) | 표에 걸리는 근거 문장 자체가 없음 — 규칙대로 판정 불가 처리 |

**추가로 수신 거부 별도 칸 검증**(2절): "今後のご連絡はご遠慮いただきたく存じます。次回以降の配信は中止してください。" — C4(이유 없는 거절)로 잘못 묶이기 쉬운 문장이지만, "次回以降の配信は中止"가 향후 발송 자체를 거부하는 의사라 2-2절 규칙대로 **거부**로 분리된다. 분류(C1~C8)와 수신 거부는 서로 다른 칸이라는 설계가 실제로 갈리는 사례다.

**결과**: 8분류 + 수신 거부 칸 전부 합성 사례로 최소 1건씩 걸어봤고, 모두 `criteria/g7-reply-processing.md` 1·2절의 문장 그대로 판정됐다. 새 칸이 필요한 사례는 나오지 않았다 — 즉 지금 8분류가 이 정도 다양성의 회신은 커버한다. **다만 이건 우리가 만든 가상 회신이라, 실제 일본 기업의 표현 다양성(더 완곡한 거절, 방언, 업종별 관용구 등)을 대표하지 못한다.** 실제 회신 10건이 쌓이면 이 표를 다시 대조한다(`specs/g7-reply-processing.md` 「지금 쓰는 값」).

## G11 — 집계·조정 제안 구조 검증

세그먼트 2개, 조건 조합 3개에 걸친 가상의 발송 기록으로 `criteria/g11-response-aggregation.md`의 최소 표본 크기(5건)·신호 상충 판정선(20%p)이 실제로 걸리는지 확인한다.

| 세그먼트 | 조건 조합(인용 근거) | 발송 건수 | 회신 | 회신율 | 표본 부족? |
|---|---|---|---|---|---|
| S1(여성 의류) | O6 상품 개수 인용 | 8 | 3 | 3/8(38%) | 아니오 — 조정 제안 대상 |
| S1(여성 의류) | O3 코디네이트 사진 인용 | 3 | 0 | 0/3(0%) | **예 — 5건 미만, 표본 부족 표시** |
| S2(코스메틱) | O6 상품 개수 인용 | 7 | 1 | 1/7(14%) | 아니오 — 조정 제안 대상 |

**표본 부족 처리 확인**: S1의 "O3 코디네이트 사진 인용" 행은 3건이라 5건 미만 — 집계표에는 행이 남지만 조정 제안 목록에는 들어가지 않는다. **의도대로 작동함.**

**신호 상충 처리 확인**: S1 안에서 두 조건 조합의 회신율 차이가 38%p(38%-0%)로 20%p 기준을 넘는다 — `criteria/g11-response-aggregation.md` 3절대로 이 세그먼트는 **"신호 상충 — 재검토 필요"**로 올라가고, 두 조합 다 조정 제안에서 빠진다. **의도대로 작동함**(다만 이 경우는 표본 부족 조합이 섞여 있어 상충인지 표본 부족 때문인지 실제로는 사람이 함께 봐야 한다 — 이 점은 실제 데이터로 재확인이 필요한 지점으로 남긴다).

**결과**: 최소 표본 크기·신호 상충 규칙 둘 다 가상 데이터에서 실제로 갈리는 것을 확인했다. **이 표의 숫자로 G2·G3에 실제 조정 제안을 내지 않는다** — 합성 데이터는 구조 검증용이지 운영 근거가 아니다.
