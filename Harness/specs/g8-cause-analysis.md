# spec.md – 미응답·미도달 원인 분석 (G8)

## 목표
G6이 [무응답] 또는 [주소 오류]로 판정한 건마다 **왜 안 됐는지**를 가설로 세우고, **다시 시도할 가치가 있는지**를 판단한다. (2026-08-03 — 재시도 가치 판정 중 G3 적합도를 참조하는 두 항목은 G3 착수 전까지 `criteria/g8-cause-analysis.md` 2절의 잠정 규칙 "低 기본 + 3회 반복 시 강등 유지"를 쓴다)

## 맥락
대상: 큰삼촌컴퍼니 해외영업 담당자, 그리고 이 판단을 받는 뒤 작업(사람 위임 / 재수집 판단 / 반응 집계)
사용 목적: **이것은 원래 브리프에 없던 기업의 직접 요구다** — *"그냥 안 읽은 건지, 주소가 틀린 건지"*를 구분해 달라. G6이 **상태(사실)**를 내는 것과 달리, 이 기능은 **원인(해석)과 판단**을 낸다 — 산출물의 성격이 다르다.
판정 기준 정본: **`../criteria/g8-cause-analysis.md`** — 원인 가설 3종을 가르는 판정 문장, 재시도 가치를 매기는 규칙이 여기 있다. **이 Spec과 함께 반드시 읽는다.**

## 입력
**단위 — 발송 건 1개(기업 1곳)당.**

- G6 [무응답] 또는 [주소 오류] 상태 1건 + 그 판정 근거
- G5 발송 이력 — 발송일시·문안(어느 세그먼트)
- G1 관찰 근거 — 기업 규모·업종 등
- **G4 연락처 출처** — 유효 등급(직통/일반), 어디서 확보했는지
- G3 적합도(재시도 가치 판단의 재료 — G3 착수 전까지는 없음, `criteria/g8-cause-analysis.md` 2절 잠정 규칙으로 대체)

## 범위
포함: 원인 가설 3종(무시 / 도달 실패 / 조사 오류) 판정과 근거 / 재시도 가치 판단(**高/低, 단 조사 오류는 해당 없음** — `../criteria/g8-cause-analysis.md` 2절)과 근거 / 보류 판정
제외: 상태 판정 자체(G6의 일) / 재시도 실행(G9·G10의 일) / 연락처 재탐색(G10→G4) / 회신 해석(G7, 무응답·주소오류에는 회신이 없으므로 해당 없음)

## 제약
- **원인을 추측이 아니라 관찰 가능한 신호로 판정한다** — "그냥 안 봤을 것"처럼 근거 없이 단정하지 않는다
- 값과 근거를 함께 적는다. 근거는 **G4 연락처 등급 · 경과 일수 · G6 판정 근거 중 무엇을 보고 그 원인을 골랐는가**
- **[주소 오류] 건은 원인 후보에서 "무시"를 제외한다** — 전달 자체가 안 된 것이므로 상대가 무시할 기회조차 없었다
- **재시도 가치가 高라도 스스로 재시도를 실행하지 않는다.** 高는 G9(사람 위임)로, 원인이 "조사 오류"인 것은 G10(재수집)으로 넘길 뿐이다
- 미확인 값(재시도 가치의 확정 임계값)을 추정치로 채우지 않는다
- **발송 건 1개 = 판단 1단위.** 앞 건에서 내린 원인 판단이 다음 건에 남지 않게 한다

**실행 형태 — Workflow다.** 원인 판정 → 재시도 가치 판단의 순서로 돌고 **실패하면 멈춘다.** 실패 3종의 처리:

| 실패 | 처리 |
|---|---|
| 원인 판정에 쓸 신호가 부족하다(G4 등급 미상 등) | **"원인 판정 불가"로 표시**하고 재시도 가치는 `criteria/g8-cause-analysis.md` 2절의 잠정 규칙(低 기본, G3 착수 전)으로 판단한다 |
| 재시도 가치 임계값이 미확정이다 | **잠정 임계값**(기준 카드)으로 판단하고 "잠정 기준 사용"이라고 표시한다 |
| 같은 건이 반복해서 이 기능에 들어온다(재시도 후에도 또 무응답) | **반복 횟수를 기록에 누적**한다. 반복이 쌓이면 그 자체가 "가치 低"의 근거가 된다(기준 카드) |

**실행체 경계 4개**

| 경계 | 값 |
|---|---|
| 입력 | 발송 건 1개분을 **1건씩** |
| 출력 | 발송 건 1개당 원인 가설 + 재시도 가치 1행 |
| 도구 권한 | **입력 파일 읽기 + 결과 파일 쓰기까지만.** 웹 접근·메일 발송 권한 없음 |
| 독립 컨텍스트 | **발송 건 1개 = 판단 1단위.** 앞 건의 원인 판단이 다음 건에 남지 않는다 |

## 출력 형식
**파일: 발송 건 1개당 `data/원인분석/{기업식별자}-{발송일시}.md` 1개.**

- 기업 식별자 · 판단일 · 대상 G6 상태(무응답/주소오류)
- **원인 가설** — 무시 / 도달 실패 / 조사 오류 / 판정 불가 + 근거
- **재시도 가치** — 高 / 低 / **해당 없음**(조사 오류 건은 매기지 않고 G10 직행 — `../criteria/g8-cause-analysis.md` 2절) + 근거
- 이 건의 **반복 횟수**(이전에도 이 기능을 거친 적이 있으면 누적)

## 성공 기준
산출물 1건(파일 1개)마다 확인한다.
- [ ] 원인 가설이 4종 중 하나로 근거와 함께 기록됨 (근거 없는 가설 0건)
- [ ] [주소 오류] 건에 "무시"가 원인으로 선택된 경우가 없음 (0건)
- [ ] 재시도 가치가 근거와 함께 高/低로 기록됨(조사 오류 건은 **해당 없음** + G10 직행 표시로 대체 — 高/低를 억지로 매기지 않는다)
- [ ] 사용한 임계값이 확정/잠정 중 어느 쪽인지 표시됨
- [ ] 반복 횟수가 기록됨
- [ ] 판단일과 대상 G6 상태가 있음
