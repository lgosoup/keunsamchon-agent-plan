# H3 — 무응답 판정 시점 도래

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 스케줄(발송 건별 지연 타이머) |
| 트리거 조건 | 발송일시로부터 **10영업일**(`../criteria/g6-delivery-status-judging.md` 1절 잠정값) 경과, 그동안 H1·H2 신호가 없었던 건 |
| 캡처할 신호 | 없음(신호 부재 자체가 신호) — 해당 발송 건의 `{기업식별자}-{발송일시}` |
| 호출 대상 | `/g6-delivery-status-judging` |
| 인자 형식 | `<{기업식별자}-{발송일시}> + 회신 도착 여부: 없음, 조회 시점: (지금 시각)` |
| 비고 | 이 값은 잠정이라 실제 회신 도착 분포가 쌓이면 카드 쪽 값이 바뀐다. 이 Hook은 그 파일의 최신값을 매번 다시 읽어야 한다(하드코딩하지 않는다) |
