# H6 — G5 제작 모드 트리거

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 하이브리드(이벤트 + 안전장치 스케줄) |
| 트리거 조건 | 세그먼트 안에 G4 [확보] 신규 컨택이 **5건** 누적 **또는** 마지막 제작 이후 **7일** 경과 중 먼저 오는 것(`../docs/design-rationale.md` G5 참조) |
| 캡처할 신호 | 어느 세그먼트 ID인지(`data/segments/`의 최신 버전 기준) |
| 호출 대상 | `/g5-proposal-email-dispatch` |
| 인자 형식 | `제작 <세그먼트 ID>` (예: `제작 S1`) |
| 비고 | 세그먼트 하나에 문안 제작이 이미 진행 중이면 중복 트리거하지 않는다 — `data/발송대기/`에 그 세그먼트·오늘 날짜의 파일이 이미 있는지 확인 |
