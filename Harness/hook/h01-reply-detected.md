# H1 — 회신 도착 감지

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 이벤트 |
| 트리거 조건 | 발송용 메일함에 새 메일이 도착 |
| 캡처할 신호 | 메일 원문 전체(일본어) + 헤더(발신 주소·수신일시·제목·스레드 ID) + 첨부 파일명 목록 |
| 호출 대상 | `/g7-reply-processing` |
| 인자 형식 | `<회신 원문 1통 붙여넣기 — 헤더(발신 주소·수신일시·제목·스레드) 포함>` — 참조 발신 정보(어느 기업에 보냈는지 등, `data/발송기록/`에서 조회 가능하면 이어서 붙임) |
| 비고 | 스팸·광고 메일함이 아니라 이 프로젝트 발송 전용 주소로 들어온 메일만 대상. 자동응답인지 아닌지는 이 Hook이 가르지 않는다 — `skills/g7-reply-processing/SKILL.md`가 판단한다 |
