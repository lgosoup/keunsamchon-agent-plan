# H8 — G11 반응 집계 주기 실행

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 이벤트(데이터 누적 기반, 계산 필요) |
| 트리거 조건 | `data/발송기록/` 전체 건수가 마지막 집계 이후 **세그먼트×조건 조합 최소 1개가 5건 이상**(`../criteria/g11-response-aggregation.md` 1절 최소 표본 크기) 새로 채워졌을 때 |
| 캡처할 신호 | 없음 — 그냥 실행 요청(집계일은 스킬이 오늘 날짜로 자동 지정) |
| 호출 대상 | `/g11-response-aggregation` |
| 인자 형식 | 인자 없음(기본) 또는 `<YYYY-MM-DD>` |
| 비고 | 이 조건 계산(어느 조합이 5건을 넘었는지)은 이 Hook이 `data/발송기록/`·`data/집계/` 최신 파일을 직접 대조해야 한다 — 단순 스케줄이 아니라 데이터를 보고 트리거 여부를 결정하는 조건부 Hook이다. 매주 1회 정도로 "체크만" 스케줄링하고, 체크 결과 조건이 안 맞으면 호출을 건너뛰는 방식이 무난하다 |
