# H2 — 발송 결과(바운스) 감지

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 이벤트 |
| 트리거 조건 | 발송 서비스(메일 인프라)가 특정 발송 건에 대해 바운스·수신 실패 응답을 반환 |
| 캡처할 신호 | 어느 발송 건인지(수신 주소로 `data/발송기록/`을 역조회해 `{기업식별자}-{발송일시}` 특정) + 바운스 코드 원문 + 조회 시점 |
| 호출 대상 | `/g6-delivery-status-judging` |
| 인자 형식 | `<발송 기록 파일 경로 또는 {기업식별자}-{발송일시}> + 그 건의 메일 시스템 응답을 그대로 붙여넣기(바운스 코드 원문 · 회신 도착 여부 · 조회 시점)` |
| 비고 | H1(회신 도착)과 이 Hook은 서로 다른 신호다 — 회신은 "왔다"는 사실, 바운스는 "실패했다"는 사실. 한 발송 건에 둘 중 하나만 온다 |
