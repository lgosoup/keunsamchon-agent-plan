# H7 — G10 재수집 주기 실행

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 스케줄(대상별 지연 타이머) |
| 트리거 조건 | 각 재수집 후보 건에 대해 마지막 판정으로부터 **30일** 경과(`../docs/design-rationale.md` G10 참조) |
| 캡처할 신호 | 유입 소스(G4 미확보 / G1 판정불가·G2 미분류 / 외부 시간경과·트렌드) + 대상 기업 식별자 |
| 호출 대상 | `/g10-recollection-judging` |
| 인자 형식 | `<유입 소스> <기업 식별자 1개>` (외부 신호면 무엇이 바뀌었는지 설명을 이어서 붙임) |
| 비고 | G4 미확보 승격 조건(**재수집 3회째**, `../specs/g10-recollection-judging.md` — 2026-08-10 확정)도 이 Hook이 판단할 계산이 아니라 `g10-recollection-judging` 스킬 자신이 호출 시점에 판단한다 — 이 Hook은 30일 경과 여부만 계산해서 부른다. **이력**: 처음엔 "14일 이상 지속 또는 3회째"였으나 30일 재확인 주기와 상충해(리스크 45) 14일 조건을 빼고 3회째 단독 기준으로 정리했다 |
