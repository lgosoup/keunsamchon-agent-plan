# H11 — G9 위임 브리프 생성 (주기)

| 항목 | 내용 |
|---|---|
| 트리거 종류 | 스케줄 |
| 트리거 조건 | **주 1회**(`../docs/design-rationale.md` G9 "큐 방치 판단 시점 = 7일" — G4 잔여 목록을 훑어보는 것과 같은 주기를 재사용, 새 리듬을 만들지 않는다) |
| 캡처할 신호 | 그 주에 새로 쌓인 **G4 [미확보]** 건 전체 + **G8 재시도가치 高** 건 전체 |
| 호출 대상 | `/g9-handoff-brief` |
| 인자 형식 | 건별로 반복 호출 — `<경로1\|경로2> <기업식별자> [경로2인데 G8 파일이 없으면 근거를 이어서]` — **"G4 미확보"·"G8 재시도高" 같은 서술형이 아니라 `skills/g9-handoff-brief/SKILL.md` 「인자」 절이 쓰는 리터럴 토큰 "경로1"·"경로2"를 그대로 넘긴다**(2026-08-10 정정 — 처음엔 이 카드 자체가 스킬 계약과 다른 표현을 써서 더미 호출이 전부 되돌려지는 버그가 났었다) |
| 비고 | **"몇 건 쌓이면 도는가"는 정의하지 않는다.** `../specs/g9-handoff-brief.md` 「입력」의 단위가 "기업 1곳씩"이라 배치로 묶어야 할 효율상 이유가 없다(G5의 "5건 누적"은 세그먼트 단위 문안 제작 때문이라 이유가 다르다). 그 주에 0건이면 실행을 건너뛴다(G11의 "0건이면 파일을 만들지 않는다" 게이트와 같은 처리) |
