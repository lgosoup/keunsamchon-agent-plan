| 항목 | 내용 |
|---|---|
| 트리거 종류 | 이벤트(H1 처리 결과에 종속) |
| 트리거 조건 | G7이 회신을 **자동응답(C6)** 또는 **수신 거부**로 판정 |
| 캡처할 신호 | G7 레코드가 낸 판정(자동응답 여부 / 수신거부 여부) + 대상 발송 건 식별자 |

| 인자 형식 | `<{기업식별자}-{발송일시}> + G7 정정 신호: 자동응답 판정됨` |
