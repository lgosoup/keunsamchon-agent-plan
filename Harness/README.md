# Harness — 제출용 패키지 (지금은 비어 있음)

**2026-08-05 — G7 전용 스냅샷을 비웠다.** 원래 이 폴더는 G7(회신 해석·정리)만 먼저 패키징해 담고 있었는데, 함수 하나씩 만들 때마다 갱신하면 "지금 폴더가 최신인지" 매번 확인해야 하고 MVP 나머지 기능(G2·G4·G5·G6)이 빠진 채로 patchwork로 남는다. **이 폴더는 원본(`specs/`·`기준/`·`.claude/`)의 스냅샷일 뿐 정본이 아니므로**(`CLAUDE.md` 4절), 비워도 잃는 내용이 없다 — G7 관련 파일은 전부 원본 자리에 그대로 있다.

## 계획

**MVP 6개 기능(G1·G2·G4·G5·G6·G7) 실행체 빌드가 다 끝나면 한 번에 패키징한다.** 그 시점에 적용할 규칙은 `docs/90_미결정과_리스크.md` 3절 ⑨-1에 미리 확인해 뒀다 — 내부 참조 경로 재작성, 기준카드 확장자 확인, 운영변수 정본 동봉.
