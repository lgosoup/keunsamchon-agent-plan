## 0. 관찰 항목 코드 — 다른 기능이 이 코드로 이 카드를 참조한다

**코드는 `../specs/G1_대상기업발굴.md` 출력 형식이 정본이고, 이 카드가 각 항목의 판정 방법을 정한다.** 뒤 작업(세그먼트화 등)이 *"어느 항목을 축으로 쓸 수 있나"*를 판단할 때 이 표를 본다. **코드를 바꾸면 그 기능들이 조용히 어긋나므로 바꾸지 않는다.**

| 코드 | 항목 | 이 카드의 어디 | 필수 조건인가 | **뒤 작업의 분류축으로 쓸 수 있나** |
|---|---|---|---|---|
| **O1** | 기업 식별 (원어명·영문명·URL) | — (메타) | 아니오 | **못 쓴다** — 식별자다 |
| **O2** | 취급 품목 | 1절 조건 3의 재료 | 아니오 | **쓸 수 있다** |
| **O3** | 제품 사진 보유 | **1절 조건 1** | **예** | **못 쓴다** — 필수 조건이라 **통과분은 전원 「있음」**이다 |
| **O4** | 커머스 보유 | **1절 조건 2** | **예** | **못 쓴다** — 같은 이유로 통과분은 전원 「있음」 |
| **O5** | 업종 | **1절 조건 3** | **예** | **쓸 수 있다** — 필수 조건이지만 통과 후에도 패션·뷰티·푸드 **세 값이 남는다** |
| **O6** | 규모 신호 (상품 수·채널 수·資本金·従業員数·설립연도) | 2-1절 | 아니오 (관찰만) | **쓸 수 있다** |
| **O7** | 한국 진출 신호 4종 | **1절 조건 4** | **예** | **조건 자체는 못 쓴다**(통과분 전원 O). **하위 신호 4종은 쓸 수 있다** — 어느 신호로 걸렸는지가 기업마다 다르다 |
| **O8** | 광고 메일 거부 표시 | 2-2절 | 아니오 (관찰만) | **못 쓴다** — 발송 가능 여부이지 문안의 성격이 아니다 |
| **O9** | 판정 불가 사유 | 3절 | — | **못 쓴다.** 단 **축약표에 반드시 남긴다** — 값이 비어 있는 것과 값이 「없음」인 것은 다르다 |

> **필수 조건을 축으로 쓸 수 있는지는 "통과 후에도 값이 갈리는가"로 갈린다.** O3·O4는 갈리지 않고, O5는 세 값이 남고, O7은 조건은 하나지만 하위 신호가 갈린다. **이 구분을 놓치면 전원이 같은 값인 항목으로 묶으려 해 무리가 하나만 나온다.**

## 1. 필수 조건 4종 — 하나라도 X면 제외

**넷 다 O여야 후보다.** 순위를 매기는 항목이 아니라 **통과/탈락 게이트**다(0절 ICP hard-gate).

### 조건 1 (**O3**) — 제품이 있는가

| | |
|---|---|
| **왜 이 조건인가** | 제품이 없으면 만들 광고 사진·영상의 대상이 없다. 이 회사의 서비스는 *제품 또는 제품 사진*을 받아 AI로 모델·광고컷을 만드는 것이다 |
| **무엇을 보고 O를 주나** | 상품 상세 페이지에 **자사 제품을 찍은 사진**이 있다 |
| **O가 아닌 것** | 아이콘 · 일러스트 · 이미지컷만 있고 제품이 안 보이는 사진 · 타사 소재 사진 · 사진 없이 텍스트 목록만 |
| **못 봤을 때** | X가 아니라 **?** (판정 불가). 사유를 적는다 |

### 조건 2 (**O4**) — 온라인으로 살 수 있는가 (커머스)

| | |
|---|---|
| **왜 이 조건인가** | 광고 사진·영상을 **쓸 자리**가 있다는 뜻이다. 커머스가 없으면 만들어 줘도 걸 곳이 없어 제안이 성립하지 않는다. 그리고 커머스를 운영하면 제품 사진이 이미 존재한다(조건 1과 맞물린다) |
| **무엇을 보고 O를 주나** | 아래 넷 중 **하나 이상**. **본 것을 반드시 표시한다** |
| | ⓐ 구매·장바구니(カート) 버튼 |
| | ⓑ 가격 표시 |
| | ⓒ 결제·배송·반품 안내 페이지 |
| | ⓓ 외부 커머스 입점 링크 (라쿠텐 · Qoo10 · Amazon JP · Yahoo!쇼핑 등) |
| **⚠ 여기가 가장 자주 갈린다** | **가격만 있고 살 방법이 없는 경우** — 카탈로그형 사이트, 도매 전용(문의 후 견적), *"取扱店舗はこちら"*만 있는 브랜드 사이트 |
| **↳ 판정시트를 채우는 사람은** | **규칙을 주지 않는다. 각자 판단하고 "애매했나" 칸에 이유를 적는다.** 갈린 결과로 이 칸을 채우는 것이 시트의 목적이다 |
| **↳ 실행체(Skill)는 잠정으로** | **`?` (판정 불가) + 사유 "구매 경로 없이 가격만 확인됨"으로 둔다.** 규칙이 없는 케이스를 O나 X로 밀어 넣으면 **판정 규칙을 실행체가 발명한 것**이 되고, 그 발명이 어디에도 기록되지 않는다. 시트 결과가 오면 이 잠정 규칙을 확정 규칙으로 바꾼다 |
| **못 봤을 때** | **?** — 스크립트로 렌더링돼 상품 목록이 안 보이는 경우가 흔하다 |

### 조건 3 (**O5**, 재료는 **O2** 취급 품목) — 업종이 패션 · 뷰티 · 푸드인가

| | |
|---|---|
| **왜 이 조건인가** | 기업이 대상 영역으로 지목한 셋이고, 레퍼런스가 이 영역에 쌓여 있다 |
| **무엇을 보고 판정하나** | 취급 품목 + 회사 소개의 사업 영역 서술. **경제산업성 물판계 카테고리에 대응시킨다**(0절) |
| **패션** | 衣類・服装雑貨等 — 의류 · 신발 · 가방 · 패션잡화. JSIC 51(繊維・衣服等卸売業) 또는 織物・衣服・身の回り品小売業 |
| **뷰티** | 化粧品・医薬品 중 **화장품 쪽**. JSIC 552 医薬品・化粧品等卸売業 또는 化粧品小売業. **의약품만 다루는 곳은 뷰티가 아니다** |
| **푸드** | 食品、飲料、酒類. JSIC 52 飲食料品卸売業 또는 식품 소매 |
| **우선순위** | **패션 > 코스메틱 > 푸드.** 기업이 말한 순서이고, EC화율 관측(약 43% > 14% > 4.5%)과도 같은 방향이다 |
| **3순위를 쓰지 않는다** | 기업이 말한 업종 3순위가 기록마다 다르게 남아(헬스케어 / 주얼리) **1·2순위만 쓴다** |
| **기타로 갈 때** | 셋 다 아니면 기타 → 제외. 단 **복합 취급**(예: 패션 + 잡화)은 주 품목으로 판정하고 근거에 적는다 |

### 조건 4 (**O7**) — 한국 진출을 원하는가

| | |
|---|---|
| **왜 이 조건인가** | 기업이 말한 대상은 *"한국으로 진출하고 싶은 브랜드"*다. 이 조건이 빠지면 모집단이 "일본 커머스 전체"가 된다 |
| **⚠ 조건은 확정이지만 관찰 방법이 미정이다** | 아래 4개는 **후보**다. 판정시트로 실제 관찰률을 재서 확정한다 |
| ⓐ | 한국어 페이지 또는 한국어 표기가 있다 |
| ⓑ | 한국 브랜드 · 한국 제조 상품을 취급한다고 명시 |
| ⓒ | 한국 배송 · 한국 진출 · 한국 파트너 모집 언급 |
| ⓓ | 한국 관련 행사 · 전시 참가 기록 |
| **잠정 판정 규칙** | **4개 중 1개 이상 있으면 O** |
| **🔻 이 조건이 내려갈 수 있다** | 판정시트 10곳에서 **4개 모두 관찰률 0이면**, 이 조건을 필수에서 빼고 **적합도 항목(G3)으로 내린다.** 관찰할 수 없는 것을 필수 조건으로 두면 전부 판정 불가가 된다 |

## 2. 관찰만 하는 항목 — 판정하지 않는다

**O/X를 주지 않고 값만 기록한다.** 순위·점수는 뒤 기능(G3 적합도)의 일이다(0절 firmographics).

### 2-1 (**O6**). 회사 규모 신호

| # | 무엇을 기록하나 | 어디서 보나 |
|---|---|---|
| ⓐ | **상품 개수** — 상품 목록에서 세어진 수 (셀 수 없으면 그렇게 적는다) | 상품 목록 페이지 |
| ⓑ | **판매·입점 채널 수** + 어디인지 | 홈페이지에 명시된 외부몰 링크·오프라인 매장 안내 |
| ⓒ | **資本金 (자본금)** | 会社概要 · 会社情報 페이지 |
| ⓓ | **従業員数 (종업원수)** | 같음 |
| ⓔ | **설립연도 · 거점 수** | 같음 |

- **점수화·순위를 매기지 않는다.** 값만 적는다.
- **우리 하한은 아직 없다** — 단가 구조는 확인됐으나(2026-07-31, 비공개 보유) **최소 수주 금액이 `(미확인)`이다.** **그래서 지금은 값만 기록하고 걸러내지 않는다.** 값이 어느 구간인지의 참고선(중소기업기본법 업종별 기준)은 `../docs/33_설계근거.md` D5.

### 2-2 (**O8**). 광고 메일 거부 표시 — 관찰만, 위법 여부 판정은 뒤 작업(연락처 확보)

| | |
|---|---|
| **무엇을 기록하나** | 있음 / 없음 / ? + **그 문구를 일본어 그대로** + 어느 주소의 앞·뒤였는지 |
| **어디서 보나** | 공개된 메일 주소의 **바로 앞이나 뒤** |
| **왜 발굴 단계에서 보나** | 일본 특정전자메일법은 광고 메일에 **사전 동의(옵트인)를 원칙**으로 하고, 웹에 주소를 공개한 사업자를 예외로 둔다. **그런데 그 주소 바로 앞·뒤에 "특정전자메일·광고메일 등을 거부한다"는 표시가 있으면 예외가 적용되지 않고, 보내면 위법이다** |
| **여기서 판정하지 않는 이유** | 위법 여부 판정은 연락처 기능(G4)의 일이다. **주소를 찾는 것과 그 주소로 보낼 수 있는지는 다른 판정이다** |
| **찾아볼 일본어 문구** | 特定電子メール · 広告メール · 宣伝メール · 迷惑メール 와 お断り · 拒否 · 送信しないでください 의 결합 |

## 3 (**O9**). 못 봤을 때 — X가 아니라 ?

**"봤는데 아니다"(X)와 "못 봤다"(?)를 같은 칸에 넣지 않는다.** X는 결론이고 ?는 **나중에 다시 볼 대상**이다. 섞으면 재조사 때 어느 쪽을 다시 열어야 하는지 알 수 없다.

**? 사유 목록** (판정시트에서 고른다)

| 사유 |
|---|
| 사이트가 열리지 않는다 |
| 스크립트 렌더링으로 상품 목록을 읽을 수 없다 |
| 로그인·회원가입을 요구한다 |
| 해당 페이지가 없다 (会社概要가 없는 등) |
| 일본어 판독이 안 된다 |
| 상품 수를 셀 수 없다 |
| 그 외 (적는다) |

## 4. 최종 판정 계산

| 결과 | 조건 |
|---|---|
| **포함** | 필수 조건 4종이 **모두 O** |
| **제외** | 하나라도 **X** → 사유에 **어느 조건이 X인지** 적는다 |
| **판정 불가** | X는 없고 **?가 하나 이상** → 다시 볼 항목을 적는다 |

**이 계산은 위 관찰값만으로 다시 할 수 있어야 한다.** 조건이 바뀌면 관찰값은 그대로 두고 이 계산만 다시 한다 — 그래서 조건이 조정될 때 조사를 처음부터 다시 하지 않는다.

## 5. 아직 값이 없는 칸 — 채우지 말 것

| 무엇 | 기업에 물어야 아는 것 | 이게 없으면 못 정하는 것 |
|---|---|---|
| 목록 규모 상한 | **월 제작 캐파** `(미확인)` | 후보를 몇 개까지 만들지. 캐파를 넘는 리드는 성과가 아니라 승인 부담과 도메인 평판 손실만 남긴다 |
| 회사 규모 하한 | 단가 구조는 확인됨(비공개 보유). **최소 수주 금액** `(미확인)` | 2-1절의 자본금·종업원수를 어디서 자를지 |
| 관찰 항목 자체의 타당성 | **국내 고객사 업종·규모 분포** `(미확인)` | 국내에서 실제로 통한 고객 유형에서 신호를 **역산**해 우리 항목과 대조하는 것 |

**추정치로 채우지 않는다.** 숫자를 지어 넣으면 근거 없는 기준이 하나 늘고, 실제 값이 왔을 때 그 숫자로 판정한 결과를 전부 다시 봐야 한다.

## 6. 변경 이력

**바꾼 줄과 이유를 여기에 한 줄 남긴다.** 이유에는 **무엇을 보고 그렇게 판단했는지**를 적는다 — 이 칸이 심사에서 *"그 기준의 정확성을 검증했는가"*에 대한 답이 된다.

| 날짜 | 무엇을 바꿨나 | 왜 (무엇을 보고) |
|---|---|---|
