# G8 원인 분석 기준 — 원인을 어떻게 가르고 재시도 가치를 어떻게 매길지

> 짝이 되는 Spec: `../specs/G8_원인분석.md`
> **여기 있는 것은 "손잡이"다.** 돌려도 구조가 안 부서지는 값과 문장만 모았다.
> 고칠 때는 **바꾼 줄과 이유를 4절 변경 이력에** 남긴다.
> 작성 2026-07-30.

---

## 1. 원인 가설 판정 문장

| 입력 상태 | 관찰할 신호 | 판정 |
|---|---|---|
| G6 = [주소 오류] | (판정 불필요 — 항상) | **조사 오류.** 전달 자체가 안 됐으므로 상대가 무시한 게 아니라 우리가 잘못 찾은 것이다 |
| G6 = [무응답] + G4 등급 = **직통** | 정상 전달, 담당 창구까지 도달함 | **무시** — 담당자에게 갔는데 반응이 없다 |
| G6 = [무응답] + G4 등급 = **일반** | 정상 전달, 그러나 창구가 대표 메일·문의 폼 | **도달 실패** — 창구까지는 갔지만 담당자에게 안 넘어갔을 가능성이 높다 |
| 위 신호가 없다(G4 등급 미상 등) | — | **판정 불가** |

**"무시"와 "도달 실패"를 가르는 것은 연락처 등급 하나뿐이다.** 다른 신호(발송 시각·요일 등)는 지금 근거가 없어 쓰지 않는다.

## 2. 재시도 가치 판단

| 원인 가설 | 재시도 가치 | 왜 |
|---|---|---|
| 무시 | **G3 적합도가 잠정 상위 구간**이면 高, 아니면 低 | 담당자가 봤는데도 무응답이면, 다시 시도할 가치는 **그 기업 자체의 가치**(적합도)에만 달려 있다 |
| 도달 실패 | **거의 항상 高** — 다른 창구(딥서치로 재탐색)를 시도하면 결과가 달라질 수 있다 | 담당자에게 애초에 안 갔으므로, 경로만 바꾸면 결과가 바뀔 수 있다 |
| 조사 오류 | **재시도 가치를 매기지 않는다** — 대신 **G10 재조사 대상**으로 직행 | 연락처 자체가 틀렸으므로 "다시 시도"가 아니라 "다시 조사"가 맞는 처리다 |
| 판정 불가 | G3 적합도만으로 잠정 판단 | 원인을 모르니 가치 판단의 재료가 부족하다 |

**"잠정 상위 구간"의 정확한 선은 없다.** `기준/G3_적합도기준.md`가 아직 확정 임계값을 못 가진 것과 같은 이유다 — Q3 답이 와야 정해진다.

## 3. 반복 횟수 처리

같은 발송 건이 재시도 후에도 다시 이 기능에 들어오면(재시도했는데 또 무응답), **반복 횟수를 1 늘려 기록한다.**

| 반복 횟수 | 처리 |
|---|---|
| 1~2회 | 위 1·2절 규칙대로 정상 판단 |
| **3회 이상 (잠정)** | 원인과 무관하게 **재시도 가치를 低로 낮춘다** — 반복 자체가 "이 경로로는 안 된다"는 신호다 |

## 4. 아직 값이 없는 칸 — 채우지 말 것

| 값 | 무엇에 쓰이나 | 어디서 오나 |
|---|---|---|
| **"잠정 상위 구간"의 정확한 선** | 2절 무시 항목의 재시도 가치 판정 | `12` Q3 — `기준/G3`과 공유 |
| **반복 횟수 임계값(3회)의 확정치** | 3절 자동 강등 시점 | 실제 재시도 데이터 |
