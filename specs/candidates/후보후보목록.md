# 후보후보 목록 — G1 투입 전 후보 기업 URL 정리용

> **용도**: G1(g1-기업판정)에 넣을 일본 패션·뷰티·푸드 기업 후보를 **기업명(원어) + 국가(일본) + 공개 페이지 URL** 형태로 미리 모아두는 파일.
> **왜 따로 만드는가**: 후보목록.md는 G1이 판단까지 마친 최종 산출물이라 거기에 넣기 전 단계의 후보를 섞어 두지 않는다 — 후보후보목록은 "아직 판정 안 한, 넣기 전의 후보"만 둔다.
> **처리 방식**: 이 파일에서 기업 1곳씩 골라 g1-기업판정 스킬에 넣으면, G1이 관찰·판정해서 후보목록.md 끝에 섹션을 추가한다. **지금은 G1 처리(4번)는 안 한다 — 후보후보목록만 채우는 단계까지.** 이 파일은 나중에 G1에 넣을 후보들이 모이면 쓰고, 다 넣은 뒤에는 비우거나 이력을 남겨 둘 수 있다(사용자 결정).
> **중복 처리**: 후보목록.md에 이미 판정 완료로 들어간 기업(식별자 기준)과 겹치면 후보후보목록에서 제외한다 — "이미 있는 거면 넘어가는 걸로" 방침 반영.
> **규칙**: 기업 1곳 = 1행. URL은 홈페이지(상품 목록·회사 개요 확인 가능한 쪽) 우선. 같은 운영사·같은 그룹의 여러 브랜드가 있으면 대표 1곳만 적는다(2026-08-12 emoda 사례에서 확인 — 같은 회사를 여러 번 후보에 넣지 않는다).

## 명단 출처(잠정) — 2026-08-13 기준

**잠정: Qoo10·라쿠텐 판매자 페이지에서 사람이 직접 판매자(page)를 보고기업명(원어) + 공개 페이지 URL을 주워 온다.**

- 이 값은 `docs/11_대안탐색_비교.md` 9절이 정본. 다른 문서는 이 파일 안에 소스 이름을 복제하지 않는다.
- **약식·robots 리스크는 확인하지 않고 잠정 채택** — Qoo10·라쿠텐 판매자 페이지를 사람이 수동 열람할 때도 동일 리스크(소셜 대량 영업 계정 정지 전례 `13S` F12)가 적용될 수 있다. **최종 확인은 기업 질문지 N28로 대기 중.**
- **이 값은 바뀔 수 있고, 바뀌면 이 절만 고치면 된다.** 약관 확인 결과나 기업 답(N28)에 따라 다른 소스(업계 디렉토리·전시회 참가기업 목록 등)로 교체될 수 있다.

⚠ **현재 내 도구 환경의 한계 (파일럿 노트, 후보후보목록 작성 시에만 참고)**
- `Qoo10.jp` / `rakuten.co.jp`는 WebFetch 직접 접근이 안 된다(Qoo10: 서버 오류, 라쿠텐: 403 Forbidden).
- 웹검색도 일본 판매자 목록·스토어명이 거의 안 잡힌다.
- 그래서 지금 단계에서는 **실체 확인되는 브랜드 자사몰 URL을 내가 직접 WebFetch로 확인한 것만** 이 파일에 넣을 수 있다. Qoo10·라쿠텐 판매자 페이지에서 마이너 브랜드까지 긁으려면 검색이 받쳐주거나, 네가 직접 판매자 페이지를 열어 알려줘야 한다. **향후 L 실행체(명단 수집용)가 생기면 그때 병렬·수동 여부를 다시 볼 수 있다(주의: 지금은 서브에이전트 병렬로 조사하는 방식은 쓰지 않는다 — 5번 안 함).**
