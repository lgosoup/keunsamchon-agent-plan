# spec.md – 일본 대상 기업 발굴 (G1)

## 목표
일본 기업 1곳의 공개 페이지를 열어 **관찰 항목 O1~O9**를 기록하고, **타겟 조건 4종**(제품 있음 / 커머스 있음 / 업종이 패션·뷰티·푸드 / 한국 진출 희망) 충족 여부를 판정해 **근거가 붙은 후보 목록 1행**을 만든다. 앞 단계로 주어진 소스에서 기업 명단을 수집하는 것까지 포함한다.

## 맥락
대상: 큰삼촌컴퍼니 해외영업 담당자, 그리고 이 목록을 받아 쓰는 뒤 작업(세그먼트화 · 적합도 평가 · 연락처 확보)
사용 목적: 제안 메일을 보낼 후보 기업을 **근거와 함께** 골라낸다. 파는 것은 *제품 사진만 있으면 AI로 광고용 모델 사진·영상을 만들어 주는 서비스*이므로, 제품과 커머스가 없는 기업은 제안이 성립하지 않는다.
왜 근거가 산출물인가: 기업은 이미 Qoo10·라쿠텐에서 수백 개 리스트를 뽑아 봤고 **검증을 하지 못했다**. 병목은 목록을 만드는 일이 아니라 **뽑은 것 중에서 근거를 갖고 고르는 일**이다.
판정 기준 정본: **`../기준/G1_기업판정기준.md`** — 무엇을 보고 O/X를 주는가, 조건 4종의 상세 정의, 외부 표준 근거가 여기 있다. **이 Spec과 함께 반드시 읽는다.**
판정해 보는 양식: `../기준/판정시트_G1.md`

## 입력
**단위 J (기업 판정) — 1건씩 넣는다**
- 기업명(원어) + 국가(일본) + 공개 페이지 URL 1개 이상 (홈페이지 / 상품 목록 / 회사 개요 / 입점몰 중 아는 것)
- URL이 홈페이지 하나뿐이어도 성립한다. 나머지 페이지는 그 안에서 찾는다.
- **여러 기업을 한 번에 넣지 않는다** (제약 참조)

**단위 L (명단 수집) — 소스 1개씩 넣는다**
- 소스 1개의 진입 URL + 수집 범위(카테고리·페이지 수) + 이미 수집된 명단(중복 제거용)
- **어느 소스를 쓸지는 이 작업이 고르지 않는다.** 밖에서 지정해 준다. 현재 후보는 일본 커머스 플랫폼(Qoo10·라쿠텐 등) / 업계 디렉토리·협회·전시회 참가기업 목록.

## 범위
포함: 주어진 소스에서 명단 수집·중복 제거(L) / 기업 1곳 공개 페이지 관찰(J) / 관찰 항목 O1~O9 기록 / 타겟 조건 4종 판정 / 제외 판정과 사유 / 판정 불가 판정과 사유 / 수집일·수집 주체 기록
제외: 국가 선정(일본으로 확정됨) / 어느 소스를 쓸지의 선택 / 비슷한 기업끼리 묶기(세그먼트화) / 적합도 점수·순위 / 연락처 탐색과 그 주소로 보낼 수 있는지의 판정 / 메일 제작·발송 / 재수집 주기 결정

## 제약
- 공개 정보만 쓴다 — 로그인·회원가입 화면, 유료 DB, 추측으로 채운 값 금지
- 값과 근거를 함께 적는다. 근거는 **본 페이지 URL + 그 페이지에서 무엇을 봤는지**
- 관찰과 판정을 다른 칸에 쓴다 — 관찰층은 "무엇을 봤다", 규칙층은 "그러므로 무엇이다"
- **"봤는데 아니다"(X)와 "못 봤다"(?)를 같은 칸에 넣지 않는다** — X는 결론, ?는 다시 볼 대상
- 일본어 원어 표기를 번역으로 덮어쓰지 않는다
- 개인을 수집하지 않는다 — 개인 이름·개인 SNS 계정·개인 직통 연락처 금지. 법인 공개 창구만
- 메일 발송·외부 전송 도구에 접근하지 않는다
- 미확인 값(월 제작 캐파, 최소 수주 금액, 발송량)을 추정치로 채우지 않는다
- **기업 1곳 = 작업 1단위.** 앞 기업을 보며 관찰한 내용이 다음 기업 판정에 남지 않게 한다

## 출력 형식
**파일: 기업 1곳당 `candidates/{기업식별자}.md` 1개.** 기업식별자는 홈페이지 도메인을 쓴다(예: `example-co-jp`).
목록으로 볼 때는 이 파일들을 모아 `candidates-{수집일}.md` 한 표로 합친다 — **합치는 것은 별도 작업이고, 판정 단위는 파일 1개다.** (한 파일에 여러 기업을 이어 쓰면 앞 기업 맥락이 다음 판정에 새어 제약을 위반한다)

관찰층 — 각 칸에 「값 + 근거」 또는 「? + 사유」
- **O1** 기업명(원어) · 영문명 · 홈페이지 URL
- **O2** 취급 품목 (원어 그대로) + 대표 품목 3개 이내
- **O3** 제품 사진 보유 — 있음 / 없음 / ?
- **O4** 커머스 보유 — 있음 / 없음 / ? + **본 것 표시**(구매·장바구니 버튼 / 가격 표시 / 결제·배송 안내 / 외부몰 입점 링크)
- **O5** 업종 — 패션 / 뷰티 / 푸드 / 기타
- **O6** 규모 신호 — 상품 개수 · 판매채널 수 · 資本金 · 従業員数 · 설립연도 (각각 값 또는 「기재 없음」). **점수화하지 않는다**
- **O7** 한국 진출 신호 4종 — 한국어 페이지 / 한국 브랜드 취급 / 한국 배송·진출 언급 / 한국 행사 참가 (각각 있음·없음·?)
- **O8** 광고 메일 거부 표시 — 있음 / 없음 / ? + 있으면 **그 문구를 일본어 그대로** + 어느 주소의 앞·뒤인지
- **O9** 판정 불가 사유 — 해당 항목 + 사유
- 수집 메타 — 수집일 · 수집 주체(사람 이름 또는 실행체 ID) · 열어본 URL 전체 목록

규칙층 — **관찰층 값만으로 계산한다**
- 조건 4종 각각 O / X / ? (계산 규칙은 기준 카드)
- 후보 판정 — 포함(4종 모두 O) / 제외(하나라도 X) / 판정 불가(X 없고 ? 있음)
- 제외 사유 — 어느 조건이 X인지
- **발송 가능성 확인 필요** — O8을 그대로 옮긴다. **여기서 위법 여부를 판정하지 않는다.** 뒤 작업(연락처 확보)이 이 칸을 보고 판정한다
- 재수집 대상 여부 + 다시 볼 항목 — ?가 있으면 예

## 성공 기준
산출물 1건(파일 1개)마다 확인한다.
- [ ] 관찰 항목 모든 칸이 「값+근거」 또는 「?+사유」로 채워짐 (빈 칸 0건)
- [ ] 근거에 **URL과 무엇을 봤는지**가 모두 있음 (인상 서술만인 근거 0건)
- [ ] 관찰층 칸에 판정·결론 문장이 섞이지 않음 (0건)
- [ ] **규칙층을 지우고 관찰층 값만으로 다시 계산해 원래와 같음** (다른 행 0건)
- [ ] 판정 불가가 제외와 다른 칸에 사유와 함께 있음 (혼재 0건)
- [ ] 제외 건에 어느 조건이 X인지 적혀 있음 (사유 없는 제외 0건)
- [ ] 수집일과 수집 주체가 있음
- [ ] 일본어 원어 표기가 보존됨
- [ ] 개인 이름·개인 SNS·개인 직통 연락처가 기록되지 않음 (0건)
- [ ] O8에 문구가 있으면 일본어 원문과 위치가 함께 적혀 있음

**표본 검사 (매 건이 아니라 절차를 점검할 때)**
- [ ] 같은 기업을 두 번 돌려 규칙층 판정이 같음 (불일치 0건)

## 확인 후 채울 것
- 목록 건수 상한 ← **월 제작 캐파** (미확인, 기업 확인 필요)
- 회사 규모 하한 ← **단가·최소 수주 금액** (미확인, 기업 확인 필요)
- 관찰 항목이 사람 사이에 갈리는지 ← `../기준/판정시트_G1.md`로 **두 사람이 5~10곳 독립 판정**
- "한국 진출 희망" 4개 신호가 실제로 관찰되는지 ← 위 판정시트에서 함께 측정. **4개 모두 관찰률 0이면 이 조건을 필수에서 적합도 항목으로 내린다**
- 관찰 항목 자체가 옳게 골라졌는지 ← **국내 고객사 업종·규모 분포** (미확인). 국내에서 통한 고객 유형에서 신호를 역산해 대조한다
